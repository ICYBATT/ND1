# ND1

Studentų galutinio balo skaičiavimo programa.

## Versija
- v-pradinė

## Funkcionalumas
- Įvedamas studento vardas ir pavardė
- Įvedami namų darbų pažymiai (10 balų sistema)
- Įvedamas egzamino pažymys
- Skaičiuojamas galutinis balas pagal formulę:
  
  Galutinis = 0.4 * vidurkis + 0.6 * egzaminas

- Rezultatai išvedami lentele

## Pastabos
- Ši versija naudoja vidurkį galutinio balo skaičiavimui
